# Tic Tac Toe Game

A beginner-friendly two-player Tic Tac Toe game built with HTML, CSS and JavaScript.

## Features
- Two-player gameplay (X and O)
- Win and draw detection
- Scoreboard for wins and draws
- Restart round and reset scores buttons
- Responsive layout

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css` and `script.js` to your repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. Open the published URL shown in the Pages section.
